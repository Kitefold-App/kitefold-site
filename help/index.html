All-Spaces Task Report: help and FAQ

How to set up the report and the weekly digest, and answers to the questions people ask most.

  3. Using the report

1. Add a report to a page

  1. A Confluence admin installs All-Spaces Task Report for Confluence from the Atlassian Marketplace (in Confluence: Apps → Explore more apps).
  2. Edit any page, type / and choose All-Spaces Task Report.
  3. Open the macro's settings (the pencil on the macro) and choose what to show. The defaults show every open task in every space you can see, grouped by space.
  4. Publish the page. The first time you view it, Confluence asks you to allow access. Press Allow access, and the report loads.

Tip: set Assignee to Me (whoever is viewing) and put the report on a team page. Everyone who opens the page sees their own tasks.

2. Report settings

SettingOptions
SpacesAll spaces I can see, Only these spaces or All spaces except these. For the last two, type the space keys separated by commas, for example ENG, OPS. A space's key is in its address after /spaces/.
AssigneeAnyone, Me (whoever is viewing) or These people (pick them in the People box).
StatusOpen, Done or Open and done.
Due from / Due toOnly tasks due on or between these dates. Leave empty for any date.

3. Using the report

  • The counts at the top show how many matching tasks are open, overdue and due this week. They count every task that matches the settings, not just the rows on screen.
  • Order: overdue and soonest tasks come first, then tasks with later dates, then tasks with no due date.
  • Load more shows the next 50 tasks.
  • Tick a task to mark it done (or untick it). The change is made on the task's page, as you.
  • Each task shows its page as a link. Open it to see the task in context.

4. Set up the weekly digest

The digest posts a new page every week that lists each person with tasks overdue or due in the next 7 days. Everyone listed is @mentioned, so Confluence notifies them by email. It shows counts only, never task text or page titles.

  1. Create a page to hold the digests, for example “Weekly task digests”. Everyone who should see the digest needs to be able to view this page.
  2. Edit it, type / and add Weekly task digest. In its settings, choose which spaces to count and the day to post (Monday to Friday).
  3. Publish the page, then press Turn on.
  4. To see one straight away, press Post one now. Each digest appears as a child page called “Task digest” with the date.
  • Only people who can edit the digest page can turn it on, change its settings or turn it off.
  • If you change the macro's settings, press Save settings so the next digest uses them.
  • Digests post once on the chosen day (days run on UTC). Pressing Post one now counts as that day's post.
  • Add an All-Spaces Task Report set to Me on the same page: each digest links back to it, so people can go straight to their own list.

5. Common questions

Why does it ask me to “Allow access”? Is something wrong?

No, this is normal and happens once per person. Apps built on Atlassian Forge must ask each person before they read Confluence on that person's behalf. The report needs this so it can read tasks as you, which is what makes it show only what you're allowed to see. Press Allow access and the report loads. You won't be asked again unless the app later needs a new permission.

A task I can see in Confluence is missing from the report

Check these first:

  • Settings: the task might be outside the spaces, people, status or dates the report is set to.
  • Live docs: Confluence sometimes doesn't return tasks on live docs to apps. This is a known Confluence issue that Atlassian is tracking (CONFCLOUD-81783), and it affects every app that reads tasks. Tasks on ordinary published pages aren't affected.
  • Permissions: the report only shows tasks on pages you can open, so a task on a restricted page won't appear for you even if it's assigned to you.
  • Very large sites: one report counts up to 10,000 matching tasks. If you reach that, it tells you, and you can narrow the spaces, people or dates.

If none of these explain it, email us with the page's link and we'll look into it.

Why couldn't I tick a task?

Ticking a task changes the page it's on, and the app does that as you. If you can view the page but not edit it, Confluence refuses the change and the report says: “You don't have permission to edit this task. You need edit access to the page it's on.” The tick goes back to how it was. Ask the page's owner for edit access, or ask them to tick it.

Why do two people see different numbers in the same report?

Because the report reads Confluence as whoever is viewing it. If a colleague can see a space you can't, their report includes its tasks and yours doesn't. This is on purpose: nobody sees tasks they couldn't open themselves.

How does the weekly digest work out its numbers?

First it looks at the chosen spaces as the person who last turned the digest on or saved its settings, to find who has tasks overdue or due in the next 7 days. Then it counts each of those people's tasks as that person, so each number matches what they'd see in their own report set to “Me”. Tasks with nobody assigned aren't included, because there's nobody to remind.

Anyone who can view the digest page can see the names and counts on it, so put it under a page that the right people can see.

What counts as “due this week” and “due soon”?

Due this week means open tasks due today or in the next 6 days (7 days in all), by your own calendar date. Overdue tasks are counted separately. The Due soon label marks tasks due today or in the next 2 days.

Does the app copy or store our tasks?

No. Tasks are read from Confluence when the report loads and aren't saved anywhere. The only thing the app stores is each weekly digest's settings. The app runs on Atlassian Forge and sends nothing outside Atlassian. See the privacy policy for the details.

The report says the licence isn't active

The app needs an active licence on your site (it's free for sites with up to 10 users). A Confluence admin can check or renew it in Confluence under Apps → Manage apps.

How do I stop the weekly digest?

Open the page with the Weekly task digest macro and press Turn off. Digests already posted stay as normal pages, and you can delete them like any other page. If the digest's page is deleted, the digest turns itself off.

6. Contact support

Email hello@kitefold.app. We aim to reply within two working days (UK). It helps to include:

  • your Confluence site address (for example yourcompany.atlassian.net)
  • the page with the report or digest
  • what you expected and what happened, with a screenshot if you can

Please don't send passwords or API tokens. We'll never ask for them.
