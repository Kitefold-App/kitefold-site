Query & Bulk Actions

Moving from CQL Search or Bulk Action Tools before Connect ends

CQL Search and Bulk Action Tools, both by StreamlineSoft, are Connect apps. Atlassian's support for Connect apps ends on 31 January 2027. After that, Atlassian will only fix critical security problems in Connect, and it expects breakages to become more frequent, some without advance notice. Query & Bulk Actions is built on Atlassian Forge and covers the searching of the first and most of the bulk changes of the second. Here's what moves where, and how to move your CQL Query macros.

As of 20 November 2026, the Marketplace lists CQL Search at version 1.1.3 (July 2024) and Bulk Action Tools at 1.0.7 (February 2022), both Connect versions. StreamlineSoft may still release Forge versions; check their listings before you decide.

Moving your CQL Query macros

There's no automatic converter. Each macro is replaced by hand, which takes a minute or two a page. Both apps can be installed at the same time, so you can move pages gradually.

  1. Install Query & Bulk Actions (a Confluence admin does this once; it's free for up to 10 users).
  2. Find the pages that use the old macro. In the app, run macro = "cql-query". CQL Search's macro is stored under that name, and Confluence finds pages by a macro's stored name even when no app provides it any more (we checked this with a made-up macro). Save it as a search so you can come back to it, and use Export CSV for a list.
  3. On each page: edit it, open the CQL Query macro's settings and copy its CQL. Then type /, choose Query results, paste the CQL and match the settings (table below).
  4. Check the results match, delete the old macro and publish.
  5. When the search in step 2 finds nothing, CQL Search's macros are gone and it can be uninstalled.

One difference to know: the Query results macro runs as whoever is viewing the page, so each reader sees only the pages they're allowed to see.

Moving from Bulk Action Tools

  • Anyone on the site can use it, as themselves. Every change runs with the person's own permissions, so Confluence refuses what they couldn't do by hand, and each item shows Done, Skipped, Refused or Failed.
  • Pick pages by any search, not only by page tree: a label, a space, a date, a person, or a saved search.
  • A preview first, undo after. Label and watcher changes can be undone from the results.
  • Admins can hide the bulk bar for everyone in the app's settings, if they'd rather people only search.

Disclosure: Kitefold makes Query & Bulk Actions, so we're not neutral. CQL Search and Bulk Action Tools still work today, and we don't know StreamlineSoft's plans. Moving means replacing macros by hand, so try Query & Bulk Actions on a few pages first.
