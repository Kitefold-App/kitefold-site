Confluence tasks cheat sheet

Confluence tasks (also called action items) are checkboxes you can assign to someone and give a due date. Here's every way to create and manage them in Confluence Cloud, where they show up, and every setting of the built-in Task report macro, on one page you can print.

Create a task

Type or chooseWhat you get
[] then a spaceA new task on its own line. Keep typing to describe it.
/ then Action itemThe same, from the insert menu. Type the first few letters to filter it.
Action item on the toolbarThe same, with the mouse.
<> then a spaceA decision, not a task: it has no checkbox and doesn't appear in task lists or reports.

Assign it and give it a due date

Inside the task, typeWhat happens
@ and a nameAssigns the task. They get a notification, and an email if they're subscribed to them. Only the first mention of someone on a page notifies them; mentioning them again on the same page doesn't. During a Confluence trial, people get the notification but no email.
@ and a teamNotifies the team's members, for teams of 50 people or fewer.
/ then DateAdds a date, which becomes the task's due date. Once it has passed, the date shows in red.
@ and a Rovo agentOpens Rovo Chat with the task's text as the prompt (where Rovo is switched on).

Finish it

  • Tick the checkbox to mark the task complete. Ticking a task changes the page, so it needs permission to edit that page.
  • No reminders. Confluence doesn't notify anyone when a due date arrives or passes (CONFCLOUD-35150). See how to send a weekly reminder for what you can do instead.

WhereWhat it showsMore

Task report macro settings

Edit a page, type /task report and choose Task report. Its settings, as Atlassian lists them:

SettingWhat it doesDefault
Space(s) and Page(s) (required)Only tasks in the spaces, pages and live docs you enter. You can mix spaces and pages.The space the page is in
Label(s)Only tasks on pages with these labels (comma-separated)None
Assigned toOnly tasks assigned to these peopleAnyone
Created byOnly tasks created by these peopleAnyone
Created afterOnly tasks created on or after this date, written dd-mm-yyyyNone
Task status (required)Complete or incomplete tasksIncomplete
Number of tasks to displayRows per page of results: 10, 20 or 4020
Display columnsAny of description, due date, assignee, location, complete date and labelsDescription, due date, assignee, location
Sort byDue date, assignee or title, with a Reverse sort boxDue date

Good to know:

  • There's no due-date filter and no "overdue only" option: sort by due date instead (finding overdue tasks).
  • Every space has to be entered one by one; there's no "all spaces" option (CONFCLOUD-71390).
  • The macro can't be added to a live doc yet. Add it to a page, or convert the live doc to a page.
  • It has no wiki markup form, and the Task report template creates a page with the macro already on it.

For admins and developers

  • REST API: GET /wiki/api/v2/tasks lists the tasks the caller can see. Useful filters: status=incomplete, assigned-to=<account id>, due-at-to=<time in milliseconds>, space-id and body-format=storage for the task text. Results come in pages: follow _links.next until it's gone.
  • In the page's storage format, a task list is <ac:task-list> holding one <ac:task> per task, each with an <ac:task-status> (incomplete or complete) and an <ac:task-body>.

Need it across all spaces?

The Task report only covers the spaces you list, and has no overdue filter or counts. All-Spaces Task Report shows every task from every space you can see in one report, overdue first, with counts by space or person, and can post a weekly digest that @mentions everyone with overdue tasks.
