What it does

One report, every space

Add the All-Spaces Task Report to any page. It lists tasks from all the spaces you can see, from chosen spaces only, or from all spaces except some.

Filters that matter

Show tasks for anyone, for chosen people, or for “Me”, so each viewer sees their own list. Pick open or done tasks, a due date range, or only overdue tasks.

Grouped and in order

Group by space, page or person. Overdue and soonest tasks come first, and each task links to its page.

Counts you can trust

The header shows how many tasks are open, overdue and due this week across everything that matches, not just the rows on screen.

Tick tasks off in place

Mark a task done or not done from the report. The change happens on the task's page, as you, so it only works on pages you can edit.

A weekly digest

The Weekly task digest posts a new page each week listing each person with tasks overdue or due in the next 7 days, and @mentions them so Confluence emails them.

Built so nobody sees too much

A report that reaches across every space has to be careful. These are the rules the app follows.

  • The report reads Confluence as you. Confluence decides what you can see, so tasks in restricted spaces or pages never appear for people who can't open them.
  • The digest counts each person as themselves. Each number on the digest page is what that person would see in their own report. It shows counts only: no task text and no page titles.
  • No task data is stored. Tasks are read when the report loads and aren't saved. The only thing stored is each digest's settings.
  • Nothing leaves Atlassian. The app runs on Atlassian Forge and makes no calls to outside services. No analytics and no AI.
