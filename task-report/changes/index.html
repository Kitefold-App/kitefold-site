All-Spaces Task Report

What's new

Changes to All-Spaces Task Report, newest first.

November 2026: Help and review links on the weekly digest

  • Help and review links. People who can edit a weekly digest's page now see Help and Leave a review links under its settings.
  • A one-time review request. After a site's first scheduled digest posts, those editors see one short line asking for a Marketplace review, until someone presses Dismiss. It never gets in the way and nothing changes whether you leave one or not. Readers of the page and of the digests never see it.

3 November 2026: now on the Atlassian Marketplace

The first public release. It includes:

  • One report, every space. Add the All-Spaces Task Report to any page to list tasks from all the spaces you can see, from chosen spaces, or from all spaces except some.
  • Filters. Tasks for anyone, chosen people or “Me”; open or done tasks; a due date range; or only overdue tasks.
  • Grouping and counts. Group by due date, space, page or person. The header counts open, overdue and due-this-week tasks across everything that matches.
  • Tick tasks off in place. Mark a task done or not done from the report, on pages you can edit.
  • Weekly task digest. A new page each week listing people with tasks overdue or due in the next 7 days, with @mentions so Confluence emails them.
  • Very large sites. One report counts up to 5,000 matching tasks; beyond that the counts show a “+” and the report says so (more in Help).
  • Reads Confluence as you. The report loads tasks from your browser through Atlassian, so it only shows what you're allowed to see (privacy policy).

Have an idea?

Email support@kitefold.app with what you'd like the report to do. When a request ships, it's listed here.
